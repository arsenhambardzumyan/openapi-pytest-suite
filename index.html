How the spec gets caught lying

Documented behaviour becomes assertions. Point the suite at your API and every place where the spec and the server disagree turns into a failing test:

pip install pytest
ATG_BASE_URL=https://api.yourcompany.com \
ATG_API_TOKEN=... \
ATG_DRY_RUN=0 python3 -m pytest tests/ -q

Credentials come from environment variables. Nothing secret is written into the files.
